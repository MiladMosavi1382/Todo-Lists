# Todo List Application

## Description
A simple task management application developed using Python.

## Features
- Add new tasks
- Display all tasks
- Delete tasks
- Mark tasks as completed
- Save tasks in JSON file

## Project Structure

```text
Todo-Lists/
│
├── main.py
├── tasks.py
├── readme.md
│
└── data/
    └── task.json
```

## Requirements
- Python 3.x

## How to Run

```bash
python main.py
```

## Data Storage
Tasks are stored in data/task.json.

## GUI
The application uses Tkinter
to provide a graphical user interface.

## Features
- Graphical desktop interface
- Add, delete and complete tasks
- JSON file storage
- Automatic data saving
## How to Use

1. Run the application using Python.
2. Enter a task title and click Add Task.
3. Select a task and click Complete Task.
4. Use Undo Completed to restore a task.
5. Select a task and click Delete Task.

## Data Storage

Tasks are automatically saved in data/task.json.
