# Todo List Application

## Description
A simple task management application developed using Python.

## Features
- Add new tasks
- Display all tasks
- Delete tasks
- Mark tasks as completed
- Save tasks in JSON file

## Project Structure

```text
Todo-Lists/
│
├── main.py
├── tasks.py
├── readme.md
│
└── data/
    └── task.json
```

## Requirements
- Python 3.x

## How to Run

```bash
python main.py
```

## Data Storage
Tasks are stored in data/task.json.
